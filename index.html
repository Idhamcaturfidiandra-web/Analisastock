Riwayat harian

Ringkasan setiap kali data disimpan, per tanggal stok. Dipakai untuk melihat perkembangan dari hari ke hari.

Aturan yang dipakai

  • Database utama = Stock Qty and Value. Satu baris = satu SKU (No Item). Nilai = kolom Value (Cost Amount Actual + Expected), sama dengan report.
  • Class = kolom Function Class dari Report ABCD Class, dicocokkan dengan No Item. Item yang tidak ada di report itu masuk "Tanpa Class". Jika Report ABCD Class belum diupload, dipakai Item Class By Value dari Stock Qty and Value.
  • Consignment tidak dianalisa: item dengan Type CONSIGNMENT atau nama item diawali C/ dikeluarkan dari semua kartu Summary (kecuali Stockout Planogram). Di Detail Item tetap tampil dengan status Repsis "Consignment".
  • Repsis = No Item ada di Stock Qty and Value dan di Replenishment Calculation by Date. Non Repsis = hanya ada di Stock Qty and Value. Hanya di Repsis = ada di Replenishment tapi tidak ada di Stock Qty and Value.
  • Kondisi stok item Repsis memakai Qty di Stock Qty and Value (item yang tidak ada di file stok = 0), dibanding Minimum / Maximum Stock di file Replenishment: Minus (< 0), Stok 0, Di bawah Min (di bawah Minimum Stock), Normal (Minimum Stock s/d Maximum Stock), Over Max (di atas Maximum Stock).
  • Nilai Over Max = (Qty Stock Qty and Value − Maximum Stock) × harga pokok per unit (Value ÷ Quantity dari Stock Qty and Value).
  • Perlu order = item Repsis yang Qty di Stock Qty and Value di bawah Minimum Stock dan tidak ada Outstanding PO maupun Outstanding TR (termasuk TR dari store lain).
  • Stockout Planogram: dihitung per baris Item Planogram (item di beberapa lokasi dihitung beberapa kali), Consignment ikut dihitung. Repsis = No Item ada di Replenishment. Stock = Nol = Qty di Stock Qty and Value tepat 0 (minus tidak termasuk; item yang tidak ada di file stok dihitung 0). Stock < Half Capacity = Qty di bawah setengah Capacity baris tersebut, termasuk Qty 0 dan minus (item Stock = Nol juga masuk di sini). % = dibagi ∑ Item kelompoknya.
  • Cover (hari) = Qty Stock Qty and Value ÷ Average Sales per hari. Kosong jika Average Sales 0.
  • Item Non Repsis dikelompokkan dari Quantity: Ada stok (> 0), Stok 0, Minus (< 0).
  • Update = ganti, bukan tambah. Upload Stock Qty and Value baru menghapus seluruh item Stock Qty and Value yang lama lalu menggantinya dengan isi file baru. Begitu juga Replenishment Calculation by Date, Report ABCD Class, dan Item Planogram. Item yang tidak ada di file baru tidak akan muncul lagi di dashboard. Yang tetap disimpan hanya ringkasan angka per tanggal di Riwayat harian (tanggal yang sama ditimpa).
